Cara main

  • 🎯 Limit: substitusi dulu. Kalau hasilnya 0/0, faktorkan lalu coret, atau kalikan dengan akar sekawan. Untuk x → ∞, bandingkan suku berpangkat tertinggi.
  • 📈 Turunan: (axⁿ)' = n·a·xⁿ⁻¹. Perkalian (uv)' = u'v + uv', pembagian (u/v)' = (u'v − uv')/v², rantai: kalikan dengan turunan bagian dalam. f'(a) = gradien garis singgung di x = a.
  • ⛰️ Aplikasi Turunan: titik stasioner saat f'(x) = 0; f naik bila f'(x) > 0, turun bila f'(x) < 0. Untuk nilai maksimum pada interval, cek juga ujung interval.
  • 🧱 Integral: ∫axⁿ dx = a/(n + 1)·xⁿ⁺¹ + C. Integral tentu = F(b) − F(a). Luas selalu positif.
  • Isi pecahan dengan tombol / (mis. 2/3) dan negatif dengan −. Pada isian koefisien, ketuk kotaknya dulu. Mudah dan Sedang kelas 11, Sulit kelas 12.
